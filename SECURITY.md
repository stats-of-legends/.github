# Politique de sécurité

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.** Écrivez à l'adresse de contact de l'organisation (profil GitHub `stats-of-legends`) avec :
- le composant touché (URL, route d'API, dépôt) ;
- les étapes de reproduction ;
- l'impact estimé.

Nous accusons réception sous 72 heures et vous tenons informé jusqu'à la correction. Merci de ne pas divulguer la faille avant qu'elle soit corrigée.

## Périmètre

- Le site Stats Of Legends et son API `/api/v1`.
- Les dépôts de l'organisation `stats-of-legends`.

Hors périmètre : déni de service volumétrique, ingénierie sociale, services tiers (Riot Games, hébergeur, prestataires).
