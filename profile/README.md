# Stats Of Legends

Statistiques League of Legends approfondies, puis multi-jeux Riot, univers de Runeterra en 3D et communauté.

| Dépôt | Rôle |
|---|---|
| `sol-platform` | Monorepo de la plateforme : web (Next.js), worker, packages par bounded context |
| `.github` | Profil, modèles d'issues et de PR, workflows réutilisables |
