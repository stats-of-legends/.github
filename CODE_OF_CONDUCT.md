# Code de conduite

Nous adoptons le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : respect, bienveillance, critiques portant sur le travail et non sur les personnes, aucune forme de harcèlement.

Signalement : adresse de contact de l'organisation `stats-of-legends`. Les signalements sont traités de façon confidentielle par l'équipe `core`.
